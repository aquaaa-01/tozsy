# 综合楼 — 校园梦核 ARG（第一阶段）

无登录、浏览器直接运行的 ARG / 互动叙事作品。

**核心玩法：没有任何"剧情播放器"。**
剧情 = 主角已经留在各信息媒介里的痕迹。
玩家在 002 博客 / 003 VV / 004 浏览器之间交叉验证，自己拼出真相。

## 运行

```bash
node serve.mjs
# → http://localhost:5173/
```

零依赖（Node 内置 http）。ES Modules + IndexedDB 需要 HTTP 环境，
**不能双击 index.html 直接打开**。

## 存档

IndexedDB（`arg-archive`）→ LocalStorage 兜底 → 内存兜底。
保存：进度 / VV 回复路径 / 已读帖子 / 搜索历史。

## 技术

原生 HTML + CSS + ES Modules，零框架零构建。

```
styles/  tokens(令牌) base(舞台+CRT) materials(纸档) oldweb(旧网页组件) pages(构图)
js/      app(路由+进度) state(三层存档)
         data/  web(官网/论坛/VV/搜索数据)
         pages/ medical blog vv web desk
         （story.js / scenes.js 为旧版遗留，未挂载）
assets/images/  图片槽位（manifest.json，aspect-ratio 锁定，换图零改码）
```
